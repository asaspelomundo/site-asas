# Asas Pelo Mundo — site

Site institucional da agência de viagens Asas Pelo Mundo (São Roque/SP).

Site estático: basta abrir `index.html` no navegador ou publicar a pasta em qualquer hospedagem (GitHub Pages, Netlify, Vercel, Hostinger…).

## Estrutura

- `index.html` — conteúdo e SEO (inclui dados estruturados TravelAgency)
- `css/style.css` — estilos, paleta e tipografia da marca
- `js/main.js` — animações (GSAP + ScrollTrigger + SplitText + MotionPath) e rolagem suave (Lenis)
- `assets/` — logo, foto da fundadora, imagem do hero e favicon

As bibliotecas de animação, as fontes (Poppins e Lora) e as fotos de destinos (Unsplash) são carregadas por CDN.
